# 07 — UI

## Goal

Plan, partially import, resume, and inspect the database through a local React + Tailwind UI after the CLI path works.

The UI is another interface to the same importer—not a browser-side reimplementation. Its Bun API plans through the shared importer and starts the real CLI as a guarded background job, while React displays source-file state, live stdout/stderr, partial progress, stored counts, and canonical events.

Start the production UI through the same maw plugin used for terminal imports:

```bash
maw jscan ui --port 4320
```

## Do

Run the complete smoke workflow:

```bash
just smoke
```

The UI portion of smoke must start the local server in the one-file-imported state, verify the plan endpoint reports one remaining file, resume safely, start a revision-guarded job through `POST /api/jobs/import`, poll `/api/jobs`, read its incremental log, load the production React document and one bundled asset, then stop the server cleanly.

Interactive imports switch automatically to the **Jobs** workspace. Each run
shows lifecycle state, timestamps, exit code, and the CLI's `[jscan]` progress.
The history is intentionally in-memory and bounded. Cancelling terminates the
child; a retry remains safe because canonical and provenance identities are
stable and a file manifest is completed only after the file finishes.

The bounded import button is intentionally two-step: it first performs a fresh
GET plan, shows the exact new/changed count and selected root, then creates a job
only after **Start import**. The Events toolbar mirrors live job progress and a
bounded committed-row window without repeatedly calling the heavyweight full
status/facet endpoints. A terminal job then performs one authoritative refresh.

Use Claude Code, Codex, or Fixture presets for their standard roots. Event
workspace/filter state is encoded in the URL, and `⌘K` / `Ctrl+K` focuses the
searchable Project / Oracle combobox.

For interactive use, run the UI recipe shown in the `justfile`, then open the loopback URL it prints.

## Private-data gate

Do not point the UI or importer at a private archive until all fixture phases
pass from a fresh database:

```bash
rm -rf .data/lancedb
just smoke
```

## Stop condition

`just smoke` proves the UI API can complete the fixture-backed import, stream a background job, reject unsafe requests, and serve the Vite build. Focused backend tests are included; there is no dedicated browser-test suite.
