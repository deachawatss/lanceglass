# Code of conduct

Be kind, specific, and curious. Critique code and decisions rather than people.
Respect privacy: never post another person's prompts, session logs, filesystem
paths, credentials, or proprietary source without explicit permission.

Harassment, discrimination, threats, and deliberate exposure of private data are
not accepted. Maintainers may edit or remove harmful contributions and restrict
participation when needed to keep the project safe and constructive.

Report conduct concerns privately through the organization contact channels or
GitHub's private reporting tools.
